# Algoritmo A* para Caminho Mínimo

Este repositório contém uma implementação simples do algoritmo **A\*** aplicada a um grafo que representa um mapa reduzido.  
O objetivo é encontrar o caminho de menor custo entre dois pontos utilizando heurística geodésica.

## 🚀 Como executar

1. Instale o Python 3
2. Baixe o arquivo main.py
3. Instale as bibliotecas e execute o programa

Opcional: faça testes com diferentes grafos para analisar o comportamento do código.
